# Module Map

This memory consolidates module structure information for quick navigation and discovery.

## Core Modules
- `diet`: day-diet, food, item, meal, recipe, unified-item
- `measure`: body measurements
- `user`: user management
- `weight`: weight tracking
- `toast`: notification system
- `search`: search infrastructure
- `recent-food`: recent foods
- `profile`: profile and charts
- `theme`: theme management

## UI Sections
Refer to `sections_ui_structure` for components per section (day-diet, unified-item, recipe, etc.)

## Where to look
- Domain layer: `src/modules/<module>/domain`
- Application layer: `src/modules/<module>/application`
- Infrastructure: `src/modules/<module>/infrastructure`
- UI sections: `src/sections`

Keep this memory as a quick index for module discovery and TODO-to-issue mapping.
